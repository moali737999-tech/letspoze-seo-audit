Top findings

ordered by severity
Critical

Direct navigation to every route except the homepage hangs on "Loading…"

Confirmed with a real browser (Playwright/Chromium), waiting for the DOM to stabilize: /about, /services and all 12 sub-pages, /case-studies and all 6 sub-pages, /blog and its posts, and /contact all return 200 OK but stay stuck on a loading screen even after 11+ seconds. No console errors are thrown. Only the homepage and the seasonal campaign page /saudi-national-day render correctly.

Fix: have engineering trace a direct (hard) navigation to /about in a fresh tab and find what data loader or state read never resolves.
Critical

No meta description, canonical tag, or Open Graph tags anywhere

Even the one working homepage, after full JavaScript execution, has no meta description, no canonical, and no og:* tags. Any link to the site shared on WhatsApp, Instagram, or LinkedIn shows a blank preview card.

Fix: add a unique meta description (150–160 characters) plus canonical and Open Graph tags to every route.
Critical

Zero structured data (schema.org) anywhere on the site

Zero JSON-LD blocks on either of the two pages that render. For this business type (hybrid local service with two offices plus event-based delivery), the highest-leverage missing types are LocalBusiness, Service per tool, and BreadcrumbList.

Fix: see the ready-to-paste schema below.
Critical

The site runs on both www and non-www simultaneously

https://letspoze.com/ and https://www.letspoze.com/ both return 200 OK with no redirect between them and no canonical tag pointing to either — likely duplicate content that splits ranking signals.

Fix: 301-redirect one host to the other and pick a single canonical version.
High

sitemap.xml is stale, incomplete, and contains a broken URL

Only 6 of ~24 real pages are listed, all sharing an identical (fake-looking) lastmod: 2024-03-15. The listed /events URL returns a soft 404 — the real nav item is "Case Studies", not "Events".

Fix: generate sitemap.xml dynamically from the real route table at build time.
High

The whole site returns HTTP 200 even for URLs that don't exist

/events, /llms.txt, and even a random path like /ar all return 200 OK — the server has a catch-all that serves the same index.html for any unmatched path instead of a real 404.

Fix: return a real 404/410 status for unrecognized routes at the server level.
Medium

Three h1 elements on the homepage

"Premium Event…", "COMING", and "SOON" (from a Coming Soon teaser section) — there should be exactly one h1 per page.

Fix: demote the other two to h2/h3.
Medium

No Arabic version of the core site

The whole site is lang="en" dir="ltr" — the only exception is a single seasonal campaign page. For a Saudi-first brand, this is a market-reach gap, not a bug.

Fix: a strategic call — evaluate a full Arabic version of the core site.
Low

Generic alt="brand" on partner logos

BMW, Sephora, Mercedes, and IKEA logos all share the same generic alt text instead of naming each brand.

Fix: descriptive alt text per logo.
